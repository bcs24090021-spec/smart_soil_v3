# Smart Soil 省料打印版 V1

## 零件

- `01_integrated_chassis_LOW_MATERIAL.stl`：一体式主机身与开放土样槽。
- `02_sloped_TFT_face_LOW_MATERIAL.stl`：倾斜 TFT 面板，单独平放打印。
- `03_probe_bridge_LOW_MATERIAL.stl`：探头横梁，单独平放打印后装到后柱上。
- `04_vented_service_plate_LOW_MATERIAL.stl`：底部通风检修板。

倾斜面板和探头横梁拆出来是为了避免大面积支撑；装回后仍是一个完整装置。

## Ender-3 V2 起始设置

- 喷嘴：0.4 mm
- 层高：0.24 mm（外观更细可用 0.20 mm）
- 壁线：3；土样杯区域建议 4 壁
- 顶/底层：5
- 填充：10%，Gyroid
- 支撑：先关闭；切片预览如发现导轨局部悬空，再仅开启“接触热床”支撑
- Brim：主机身 6 mm；小零件 3 mm
- PLA：按耗材标签温度开始，先做首层检查

主机身按当前 STL 方向打印，土样槽开口朝上。TFT 面板、探头横梁和底板均用最大平面贴床。

## 重要限制

这是省料结构原型，不是最终尺寸验证版。52 x 40 mm 屏幕开口、三个探头导孔、ESP32 与 pH 板空间尚未用卡尺确认。打印槽的网格是封闭的，但不代表实物一定防水；首次加水前应做独立漏水测试，或放入防水内杯。

建议先在切片软件中确认实际克数和打印时间，并先打印 TFT 开口与探头孔的小型尺寸测试件，再决定完整打印。
