# PH4502C + E201-C 独立测试

## 接线

- PH4502C `V+` -> ESP32 `5V/VIN`
- PH4502C `G/GND` -> ESP32 `GND`
- PH4502C `PO` -> 分压电阻 -> ESP32 `GPIO34`
- `DO` 不接
- 所有设备必须共地
- ST7789 `VCC` -> ESP32 `3V3`（模块明确标注 3.3-5V 时也可用 5V）
- ST7789 `GND` -> ESP32 `GND`
- ST7789 `BL` -> ESP32 `3V3`
- ST7789 `SCL/SCK` -> ESP32 `GPIO18`
- ST7789 `SDA/MOSI` -> ESP32 `GPIO23`
- ST7789 `RES/RST` -> ESP32 `GPIO33`
- ST7789 `DC` -> ESP32 `GPIO26`
- ST7789 `CS` -> ESP32 `GPIO25`

PH4502C 的 PO 可能高于 ESP32 的 3.3V ADC 上限。必须保留已经安装的硬件分压器，不能把 PO 直接接 GPIO34。

## 测试步骤

1. 打开 `PH4502CTest.ino`，选择 `ESP32 Dev Module` 并上传。
2. 打开 Serial Monitor，设置 `115200 baud` 和 `Newline`。
3. 等待至少 30 秒，确认状态为 `STABLE`。
4. 用蒸馏水冲洗探头尖端并轻轻甩掉水滴，不要擦玻璃球。
5. 把探头放入标签为 pH 9.18 的缓冲液，等连续读数不再漂移且显示 `STABLE` 后发送 `CAL918`。
6. 再次冲洗探头，放入 pH 4.00 缓冲液，稳定后发送 `CAL4`。如果先前的 `CAL4` 已保存在同一块 ESP32 上，可用 `STATUS` 确认，不必重复保存。
7. 两点校准完成后，串口才会显示计算后的 pH。

ST7789 彩屏使用横屏 `320x240`，会同时显示 ADC 电压、噪声范围、稳定状态、校准进度和 pH。开机时依次显示红、绿、蓝，用于确认彩屏供电、SPI 通讯和颜色顺序。

可发送的命令：`HELP`、`STATUS`、`CAL918`、`CAL4`、`CLEAR`。`CAL918` 必须在探头实际浸入 pH 9.18 缓冲液时发送；不要在 pH 7 液中发送，也不要把约 1944 mV 的历史观察值硬写进去。

## 注意

- 不要用普通水或蒸馏水代替 pH 校准缓冲液。
- 蒸馏水只用于短暂冲洗，不用于长期保存探头。
- 土壤测量应使用固定比例的土壤和蒸馏水制成悬液，再测上层液体；不要把玻璃液体电极强行插进硬土。
- 这套 pH 4.00 / 9.18 两点换算仅供原型初筛。此前 pH 7 缓冲液的读数不稳定，且与两点推算不一致；未排除原因前，不能声称 pH 结果已通过 pH 7 复核或用于农业决策。
- 本程序没有温度补偿；校准和测量尽量保持相近温度，并确认缓冲液标签的标称值。
