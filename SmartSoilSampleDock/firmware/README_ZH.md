# SmartSoil 现有传感器测试

本程序面向经典 ESP32 DevKit（ESP32-WROOM，PlatformIO 的 esp32dev）。ESP32-C3/S3 等板子需要重新确认板型和引脚。提供串口和 OLED 本地显示，不连接 Dashboard、Wi-Fi、AI 或后台。

## 接线：先不接 pH

| 器件 | 接口 | ESP32 |
| --- | --- | --- |
| DS18B20 | VDD | 3V3 |
| DS18B20 | GND | GND |
| DS18B20 | DATA | GPIO4 |
| DHT22 | VCC | 3V3 |
| DHT22 | GND | GND |
| DHT22 | DATA | GPIO27 |
| 电容式土壤水分模块 | VCC | 3V3，须确认模块支持 |
| 电容式土壤水分模块 | GND | GND |
| 电容式土壤水分模块 | AO/AOUT | GPIO35 |
| OLED | VCC | 3V3 |
| OLED | GND | GND |
| OLED | SDA | GPIO21 |
| OLED | SCL | GPIO22 |

- DS18B20 的 DATA 与 3V3 之间加 4.7 kΩ 电阻，使用三线供电，不用寄生供电。
- 裸 DHT22 的 DATA 与 3V3 之间加约 10 kΩ 电阻；模块可能已有上拉。依据模块标注核对引脚，不按线色猜测。
- DHT22 放在通风、干燥处，不能插泥土或浸水。它测的是空气湿度，不是土壤含水率。
- DS18B20 只有确认是防水封装后才放入湿样本；裸芯片不能直接浸水。
- 断电后接线，用 USB 给 ESP32 供电，所有模块共地。

## 上传

Arduino IDE：安装 Espressif 的 ESP32 开发板包，选择实际板型（经典 DevKit 通常为 ESP32 Dev Module），安装 OneWire、DallasTemperature、DHT sensor library、Adafruit Unified Sensor、Adafruit SSD1306 和 Adafruit GFX Library，并接受依赖安装。打开 SmartSoilSensorTest/SmartSoilSensorTest.ino，选择 USB 串口并上传，然后打开 115200 波特率串口监视器。

PlatformIO：在本 firmware 文件夹运行 `pio run` 编译，`pio run --target upload` 上传，`pio device monitor` 查看串口。

每约 3 秒输出一行 JSON；启动时另有 I2C 扫描和说明文字。温度单位 °C，空气湿度单位 %RH。数字传感器读取失败输出 null 和 sensor_error，而不是假数据。电容式土壤传感器输出 soil_adc_raw 和 soil_adc_mv，soil_moisture_pct 在校准前始终为 null。模拟脚浮空也可能产生合理电压，因此软件无法单凭数值确认探头已连接；uncalibrated_connection_unverified 不代表正常连接已验证。

## OLED 测试与土壤水分

默认使用 SSD1306 128×64 驱动，启动扫描 I2C 并选择发现的 0x3C 或 0x3D。地址扫描只能确认设备响应，不能判断控制器型号。找不到 OLED 时仍继续读取传感器；显示 ERR 表示数字传感器读取失败。pH 默认显示 OFF。

屏幕显示样本温度、空气温湿度、土壤 ADC 原始值及电压。八行均使用 8 像素行高。土壤 RANGE! 表示超出程序设定的保守 ADC 量程，检查信号与供电；这不是硬件过压保护。将探头感应区放入土中，上部电子元件和接口保持干燥。先在加水前测原始土样。

用空气/干样和湿样观察读数变化并记录，不把单次电压当成绝对含水率。下一步才能按具体土壤、插入深度和参考方法校准。屏幕全黑时检查启动扫描信息及供电接线；若地址有响应但仍不显示或错位，确认是否实际是 SH1106，本代码尚未支持该驱动。扫描后初始化成功也不保证实际画面正确。

## pH：确认转换板后再开启

E-201-C 是电极，不是能够直接接 ESP32 的模块。它必须先连接兼容的高输入阻抗 pH 转换板的 BNC 接口。请先确认实际转换板型号、供电要求和模拟输出范围。

**不能把可能输出 5V 的转换板直接接 ESP32 GPIO34。软件的量程检查不能防止硬件烧毁。** 需要先使用万用表检查，并按照板子最大输出设计分压/缓冲保护，使 ADC 输入在安全、有效范围内；不要仅凭一次正常读数判断安全。本程序按经典 ESP32 保守使用约 100–2900 mV 范围。板子若需要 5V 供电，也不代表它的信号可以直接接 ESP32。

安全确认后：转换板经过必要保护的模拟输出接 GPIO34，共地，改 PH_ENABLED 为 true。PH7_MV 和 PH4_MV 保持 NAN 时只读取电压，ph 仍为 null。

1. 使用新鲜的 pH 7 和 pH 4 标准缓冲液，不用蒸馏水替代校准液。
2. 冲洗探头，分别在两种缓冲液中等待稳定，记录多次 ph_adc_mv；数值是经过最终接线/分压后 ADC 端的电压。
3. 把稳定电压填入 PH7_MV 和 PH4_MV，重新编译上传。更改分压、转换板调节器或接线后需重新校准。
4. 用独立缓冲液复核。程序的稳定性与量程门槛只是初步保护，不能证明准确度；低成本 ESP32 ADC、探头与转换板都可能带来误差。

程序使用两点线性估算，没有实现 pH 温度补偿，也不能承诺实验室精度。在校准区间之外的结果属于外推，需额外验证。

## 放泥土的流程

放定量泥土，按选定的土壤检测方法加入固定比例蒸馏水，混合并等待规定时间，再测土水悬液的 pH 和样本温度。土水比例及等待时间必须记录并保持一致，本测试程序不替你定义农业检测标准。

E-201-C 玻璃头不要强行插入干土；测完冲洗，按探头说明书用规定保存液保存，不长期泡在泥浆或蒸馏水中。空气湿度不能用于推算原始土壤含水率，加入水后的样本也不能代表原始含水率。

当前版本不输出作物推荐或施肥剂量：这些读数不足以测出 N/P/K 或全面判断土壤肥力。
