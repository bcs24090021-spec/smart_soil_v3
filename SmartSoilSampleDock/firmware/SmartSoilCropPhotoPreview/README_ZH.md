# Word 作物照片彩屏预览

这是独立的静态预览程序：显示 Word 文件中 29 张作物照片及 V1 表格范围，另有一个无图占位的茄子页面。它不读取传感器、不计算前三作物、不调用 AI。上传它会暂时替换板上的测量程序；要恢复测量需重新上传 `../SmartSoilTFT/SmartSoilTFT.ino`。

屏幕沿用已工作的 ST7789 320x240 横屏接线：CS 25、DC 26、RST 33、MOSI 23、SCK 18。电源和背光沿用实测可工作的接法。按钮如需接入：Start 一脚接 GPIO13，另一脚接 GND；Next 一脚接 GPIO14，另一脚接 GND，内部上拉已启用。接线前断电，不要给按钮接 5V。若按钮尚未装好，可用 115200 串口发送 `s` 回第一张、`n` 看下一张。

照片来自 `../../data/crop_photos_v1/`，由 `../../data/build_tft_crop_photos.py` 转成 120x90 RGB565，保持原始比例并留边，不做中心裁切。重新生成素材后，打开本目录的 `.ino` 上传。需要 Adafruit GFX、Adafruit ST7735 and ST7789 Library 及其依赖。

照片仅用于视觉预览；范围来自尚未验证的 Word 表，特别是 VWC 不能与当前固件的相对湿润指数直接比较。公开展示或发布照片前应核实使用权。
